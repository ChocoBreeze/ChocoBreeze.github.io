## 한 줄 요약

Global X Silver Miners ETF(SIL)는 은괴를 보유하는 상품이 아니라, Solactive Global Silver Miners Total Return Index를 추종하는 주식형 ETF다. 은 가격뿐 아니라 각 기업의 생산비, 운영, 국가·환율 위험과 주식시장 여건이 수익에 영향을 준다.[^1][^2]

## 분류 근거와 기본 정보

SIL은 은 채굴 산업에 경제적으로 연결된 기업의 주식과 예탁증서를 보유한다. 물리적 은 가격에 직접 연동되는 신탁과 구별하기 위해 Silver 폴더 안에서도 은 채굴주 ETF로 설명한다.[^1][^2]

| 항목 | 내용 |
| :-- | :-- |
| 정식 명칭 | Global X Silver Miners ETF |
| 티커 / 거래소 | SIL / NYSE Arca |
| 설정일 | 2010년 4월 19일 |
| 추종 지수 | Solactive Global Silver Miners Total Return Index |
| 운용사 | Global X Management Company LLC |
| 총보수 | 연 0.65% |
| 분배 빈도 | 반기별 |

투자설명서에 따르면 펀드는 순자산의 최소 80%를 지수 구성 종목 및 관련 ADR·GDR에 투자하는 것을 목표로 한다. 일반적으로 지수를 구성 종목 비중에 가깝게 복제하지만, 거래·유동성·법적 제약이 있을 때 표본 추출 방식을 사용할 수 있다.[^2]

## 기준 데이터

Global X 상품 페이지의 가격·자산·보유종목 데이터는 **2026년 9월 25일** 기준이다.[^1]

| 항목 | 2026년 9월 25일 |
| :-- | --: |
| 순자산 | $4.74B |
| NAV | $91.62 |
| 시장가격 | $91.56 |
| 보유 종목 수 | 39 |
| 30일 중간 매수·매도 호가 차이 | 0.13% |

가격과 순자산은 이후 거래일에 달라진다. 시장가격으로 거래되므로 매수·매도 호가 차이와 체결 시점도 실제 투자 비용에 영향을 줄 수 있다.[^1]

## 보유 종목과 집중도

상위 보유 종목은 **2026년 9월 25일** 기준으로 Wheaton Precious Metals(WPM) 23.61%, Pan American Silver(PAAS) 11.25%, Coeur Mining(CDE) 10.99%, Hecla Mining(HL) 4.80%, Industrias Peñoles 4.63%였다. 상위 3개 종목만 합쳐도 순자산의 약 45.85%다.[^1]

포트폴리오는 순수 은 생산기업만으로 구성되지 않는다. 예를 들어 WPM은 광산에 자금을 제공하고 생산물 일부를 받는 스트리밍 기업이며, OR Royalties와 같은 로열티 기업도 보유 목록에 포함된다. Global X 설명과 투자설명서는 지수 대상에 은 채굴과 관련된 활동을 하는 기업을 포함한다고 밝힌다.[^1][^2]

## 성과를 읽을 때

Global X가 **2026년 6월 30일** 기준으로 제시한 연환산 총수익률은 다음과 같다. 총수익률은 해당되는 분배금을 재투자한 가정이며, 과거 성과가 이후 성과를 보장하지 않는다.[^1]

| 기간 | NAV | 시장가격 | 지수 |
| :-- | --: | --: | --: |
| 1년 | 62.96% | 62.84% | 64.15% |
| 3년 | 45.98% | 45.95% | 47.04% |
| 5년 | 13.99% | 14.00% | 14.19% |

SIL의 성과는 은 현물 가격과 같지 않다. 광산기업의 매출과 비용, 생산량, 신규 프로젝트, 자본 지출, 국가별 규제·정치 상황, 환율, 주식시장 밸류에이션이 함께 작용한다. 은 가격이 상승해도 비용이나 운영 문제가 커지면 광산주 수익률이 은 현물보다 낮을 수 있고, 반대 방향의 차이가 생길 수도 있다.[^2][^3]

## 비용과 분배

Global X와 2026년 요약 투자설명서는 총 연간 운용비용을 **0.65%**로 제시한다. 이 비율에는 펀드 운영비용이 반영되지만, 증권사 수수료와 매수·매도 시 호가 차이는 별도일 수 있다. SEC에 제출된 2026년 반기 주주보고서는 최근 6개월 비용 예시에서 연환산 0.65%를 확인한다.[^1][^2][^3]

Global X가 **2026년 9월 25일** 표시한 30일 SEC 수익률은 -0.15%였고, 분배 빈도는 반기별이었다. SEC 수익률은 과거 분배나 배당이 미래에 같은 수준으로 지급된다는 보장이 아니며, SIL을 정기 현금흐름 상품으로 간주하기 어렵다.[^1]

## 주요 위험

- **은 가격과 기업 실적의 차이**: SIL은 은 현물이 아니라 기업 주식을 보유한다. 금속 가격이 기업 이익이나 주가에 같은 비율로 반영되지 않는다.[^2]
- **산업·종목 집중**: 투자설명서는 SIL을 비분산형 펀드로 분류하며, 지수와 같이 금속·광산 산업에 집중할 수 있다고 설명한다. 일부 대형 보유 종목의 주가 변화가 전체 성과에 큰 영향을 줄 수 있다.[^1][^2]
- **운영·비용 위험**: 광산 생산 차질, 인허가, 노동·에너지 비용, 자본 조달과 프로젝트 일정이 기업별로 다르게 작용한다.[^2]
- **국가·환율 위험**: 펀드에는 미국 외 기업과 외화 표시 자산이 포함될 수 있다. 국가별 규제와 통화 변동은 미국 달러 기준 NAV에 영향을 줄 수 있다.[^2]
- **시장 위험**: 광산기업 주식은 금속 가격 외에도 금리, 투자심리와 주식시장 변동의 영향을 받으며 원금 손실이 발생할 수 있다.[^2]

SIL을 검토할 때는 보유기업과 지수 기준, 최신 상위 종목 비중, 보수, 거래 유동성과 분배 내역을 기준일을 맞춰 살펴본다. 물리적 은 신탁이나 광범위 주식 ETF와는 기초 자산과 위험 원천이 다르다.
