# 39. 라이트 모드 강조 글자 대비

초록 강조색을 글자로 쓸 때 라이트 모드에서 읽기 어려운 문제를 고칩니다. 34번 화면 확인 중 발견했습니다.

## 현재 동작

- 강조색 `--accent`(`--nv-primary`, `#76b900`)가 링크, 인라인 코드, 배지, 라벨의 글자색으로 쓰였습니다.
- `#76b900`의 명도 대비는 흰 배경에서 2.41:1입니다. WCAG AA의 일반 글자 기준 4.5:1에 못 미칩니다.
- `--accent`는 배경, 테두리, 포커스 표시 등 글자 외 용도로도 100곳 넘게 쓰입니다. 변수 자체를 어둡게 하면 강조 면과 버튼까지 바뀝니다.
- `feedback.astro`의 버튼은 정의된 적 없는 `--accent-text`를 참조해 글자색을 상속받고 있었습니다.

## 목표

1. 라이트 모드의 초록 글자가 실제 배경에서 4.5:1 이상이 되게 합니다.
2. 다크 모드와 강조 면·테두리 모양은 바꾸지 않습니다.
3. 대비가 다시 나빠지면 테스트가 잡게 합니다.

## 설계

- 글자 전용 변수 `--accent-text`를 추가합니다. 라이트 모드는 `#4a7500`, 다크 모드는 기존과 같은 `--nv-primary`입니다.
- `color: var(--accent)` 54곳을 `color: var(--accent-text)`로 바꿉니다. 배경·테두리·포커스 표시의 `--accent`는 그대로 둡니다.
- 흰 배경 위에 `--nv-primary`를 직접 쓰던 홈 화면 아이콘과 목록 표시도 `--accent-text`로 바꿉니다. 헤더·푸터는 항상 어두운 면이라 그대로 둡니다.
- 초록 배경 버튼 `.feedback-link`의 글자는 `--nv-on-primary`로 지정합니다.

### 색 선택

| 색 | 흰 배경 | `#f7f7f7` | 표 줄무늬(초록 4%) | 카드 틴트(초록 14%) |
| --- | ---: | ---: | ---: | ---: |
| `#76b900`(기존) | 2.41 | 2.25 | 2.33 | 2.14 |
| `#5a8d00`(`--nv-primary-dark`) | 4.00 | 3.74 | 3.87 | 3.56 |
| `#4f7d00` | 4.92 | 4.60 | 4.76 | 4.37 |
| `#4a7500`(선택) | 5.47 | 5.11 | 5.29 | 4.86 |

기존 `--nv-primary-dark`는 기준에 못 미칩니다. `#4a7500`은 위 네 배경에서 모두 4.5:1을 넘는 후보 중 가장 밝습니다.

## 변경 파일

- `src/styles/global.css` — `--accent-text` 정의
- `src/**/*.astro` 27개 파일 — 글자색 교체
- `e2e/color-contrast.spec.mjs`(신규)

## 검증

- 2026-11-02 빌드에서 주요 페이지 23개를 라이트·다크로 스캔했습니다. 초록 글자 스타일 38종 모두 4.5:1 이상입니다. 일회성 스캔이며, 저장소에는 대표 사례 5종의 브라우저 테스트만 남깁니다.
- 스캔으로 찾은 문제: `.feedback-link`가 교체 직후 초록 배경에 초록 글자(1.00:1)가 되어 `--nv-on-primary`로 고쳤습니다. 홈 화면 아이콘은 2.41:1이었습니다.
- 라이트·다크 화면을 캡처해 확인했습니다.

### 확인하지 못한 범위

- 스캔은 페이지가 처음 렌더링된 상태만 봅니다. 마우스를 올린 상태, 검색 팔레트처럼 열어야 보이는 화면은 포함하지 않았습니다.
- 그라데이션과 이미지 위의 글자는 계산에 넣지 않았습니다. 그라데이션 틴트는 초록 18% 이하입니다.
- 이번 변경은 초록 글자만 다룹니다. 회색 보조 글자 등 다른 색의 대비는 측정하지 않았습니다.
