# 19. ETF 탐색기와 비교

## 현재 동작

- ETF 페이지는 물리 폴더 경로에서 분류를 추출해 분류별 빠른 탐색 카드를 제공합니다.
- ETF 페이지는 기존 제목·티커 폴더명·태그를 대상으로 `q` URL 파라미터 기반 텍스트 검색을 제공합니다.
- ETF 글은 약 135개이며, 현재 10개 파일럿 글에 티커·운용사·자산군·전략·노출·레버리지·인컴 스타일 선택 필드를 적용했습니다.
- 파일럿 글은 `assetClass`·`strategy` 필터와 카드 메타데이터에 연결됩니다. 보수율·AUM·수익률 같은 변동값은 아직 공통 필드로 노출하지 않습니다.
- 비교 패널은 현재 비교 가능한 글 수와 전체 ETF 글 수를 함께 표시해 파일럿 범위를 안내합니다.
- `docs/etf/`에 분류 기준과 콘텐츠 가이드가 이미 있습니다.

## 목표

- ETF를 분류·전략·특성으로 찾고 2~4개를 나란히 비교할 수 있게 합니다.
- 변동 데이터가 기준일 없이 최신값처럼 보이지 않도록 합니다.

## 선행 조건

- 17번의 `dataAsOf`·`verifiedDate` 정책
- 18번의 필터 상태와 URL 규칙 중 재사용 가능한 부분
- ETF 분류 가이드와 일치하는 데이터 사전

## 데이터 설계 원칙

안정 데이터와 변동 데이터를 구분합니다.

- 안정 데이터: ticker, issuer, assetClass, strategy, exposure, leverage, incomeStyle
- 변동 데이터: expenseRatio, aum, yield 등
- 변동 데이터는 값과 기준일을 함께 저장하거나 비교 화면에서 제외합니다.
- 폴더 경로와 frontmatter 중 어느 쪽이 분류의 원본인지 한 곳으로 정합니다.

중첩된 `etf` 객체와 평면 필드 중 어떤 형식이 기존 콘텐츠 작업에 안전한지는 파일럿 전에 결정합니다.

파일럿에서는 기존 frontmatter 스타일과 스캐폴드 호환성을 우선해 평면 camelCase 필드를 사용합니다.

| 필드 | 성격 | 예시 | 비고 |
| --- | --- | --- | --- |
| `ticker` | 안정 | `QQQ` | 대문자 티커, 비교 화면의 식별자 후보 |
| `issuer` | 안정 | `Invesco` | 운용사·상품 제공자 |
| `assetClass` | 안정 | `Equity`, `Commodity` | 자산군 필터 기준 |
| `strategy` | 안정 | `Index`, `Leveraged`, `Physical` | 폴더 분류와 별개인 운용 방식 |
| `exposure` | 안정 | `Nasdaq-100`, `Gold` | 지수·섹터·테마 노출 |
| `leverage` | 안정 | `1x`, `3x`, `-3x` | 레버리지·인버스 설명 |
| `incomeStyle` | 안정 | `Core`, `Hedge`, `None` | 소득·인컴 성격 요약 |

`expenseRatio`, `aum`, `yield` 등 변동 데이터는 `dataAsOf` 또는 별도 기준일 없이는 추가하지 않습니다.

## 구현 단계

1. [완료] UI에 필요한 최소 안정 데이터 사전과 평면 frontmatter 형식을 파일럿 기준으로 정했습니다.
2. [완료] QQQ·QQQM·SPY·GLD·IAU·TQQQ·SQQQ·SOXL·XAR·SHLD 10개 ETF에 파일럿 메타데이터를 적용했습니다.
3. [완료] 선택 필드의 타입·허용값 검사를 추가했습니다. 기존 글의 선택 필드 누락은 허용하고, 값이 있는 필드만 공통 규칙으로 검사합니다.
4. [완료] `/etf`에 기존 글에서 안전하게 얻을 수 있는 텍스트 검색과 파일럿 안정 데이터 기반 자산군·전략 필터를 추가했습니다.
5. [완료] URL에 선택된 티커를 보존하는 2~4개 비교 화면과 비교 가능 메타데이터 커버리지 안내를 추가했습니다.
6. 변동 데이터에는 기준일을 항상 함께 표시합니다.
7. 파일럿 검토 후 나머지 ETF 백필을 여러 콘텐츠 커밋으로 분리합니다.

## 테스트 설계

- 필드가 없는 기존 ETF 글의 빌드 호환성
- 허용되지 않은 leverage·strategy 값 검증
- 같은 티커 중복과 존재하지 않는 비교 티커 처리
- 2개·4개 비교, 모바일 가로 스크롤, 긴 전략명
- URL 공유와 뒤로 가기
- 기준일 없는 변동 데이터가 비교표에 노출되지 않는지 확인
- ETF 카테고리·개별 글·검색·RSS·사이트맵 회귀 확인
- `npm test`, `npm run check:content`, `npm run check`, `npm run build`

## 범위 제외

- 외부 금융 API 실시간 연동
- 자동 매수 추천이나 개인화된 투자 조언
- 출처 없이 AUM·수익률을 자동 추정하는 기능
