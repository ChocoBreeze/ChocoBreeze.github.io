# 24. 공개 글 통계 페이지

## 목표

- 공개 글의 누적 수와 발행 흐름을 한 페이지에서 확인합니다.
- 카테고리·연도·월별 분포를 콘텐츠 데이터만으로 정적으로 제공합니다.

## 범위

- `/stats/` 정적 페이지
- 대표 카테고리별 글 수와 기존 카테고리 링크
- 표시 시간대(`Asia/Seoul`) 기준 연도·월별 발행 수
- 방문자 수, 쿠키, 외부 분석 서비스는 포함하지 않음

## 구현 상태

1. [완료] `buildBlogStats()` 집계 유틸리티와 단위 테스트 추가
2. [완료] 전체 글·날짜 보유 글·활동 연도 요약 카드 추가
3. [완료] 카테고리 분포, 연도별 막대, 월별 활동 그리드 추가
4. [완료] Footer Navigate에서 통계 페이지로 연결

## 데이터 정책

- `getPublishedPosts()`만 사용해 초안은 제외합니다.
- `pubDate`를 우선하고, 없으면 legacy `date`를 사용합니다.
- 날짜가 없거나 유효하지 않은 글은 전체 글 수에는 포함하지만 날짜 통계에서는 제외합니다.
- 카테고리 명칭과 경로는 `BLOG_CATEGORIES`/`getCategoryDefinition()`을 재사용합니다.
